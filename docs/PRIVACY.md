# Piko 隐私说明（1.0 候选版）

Piko 默认在 Windows 本地运行，不要求账户。用户可以在设置中分别关闭桌面探索、鼠标和文件活动感知。窗口几何诊断默认不包含窗口标题；文件活动观察不读取正文。

开发感知、Git 摘要、本地记忆、模型和 Agent 只读工具均默认关闭。开启开发桥接后，仅传递诊断数量、构建/测试结果、Git 计数等约定摘要；不发送源码、终端正文或仓库路径。

选择远程模型并发送问题时，会向用户配置的服务发送当前问题、当前窗口最近成功对话和已授权的情境摘要。远程服务按其自身规则处理已收到的数据；取消请求不保证撤回已发送内容或费用。本地模型仅允许回环地址。API Key 保存在 Windows 凭据管理器。

只读工具需要开启权限，再逐项选择并确认访问目录；结果仅在本地显示，不会自动加入后续模型上下文。本版本不提供任意命令执行或写文件工具。

对话历史只保留在当前窗口。若开启长期记忆，记忆保存到本地加密数据库，可在记忆窗口查看并删除全部记录；“新对话”只清空当前会话。

默认卸载保留设置和记忆。完全清除使用安装器 `--uninstall --purge-data`，同时删除 Piko 管理的设置、记忆和凭据。关闭窗口或停止请求不等于删除已保存的长期记忆。

截图、浏览器内容、完整代码和键盘内容没有在本版本开放授权。检查更新仅在用户主动触发时访问官方 GitHub Release；自动安装还必须通过完整性、签名和可信发布者检查。

问题反馈使用本仓库 Issues；安全问题按根目录 SECURITY.md 处理。正式发布者身份及最终对外联系方式仍需发布者确认。
