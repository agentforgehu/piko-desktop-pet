# Piko 下一阶段：0.2.5 可靠互动预览版

日期：2026-09-09。基线：main `14acb11273bee354d77b5f5ebffaa73d0b3a3fd0`（0.2.4）。

## 产品决策

下一状态定义为：用户能在真实模型延迟下完成“打开对话 → 发送 → 等待或停止 → 收到回复 → 有需要时确认一项只读操作”，后台在整个过程中保持可用，失败后可以继续操作。

继续 PC-first / C# / WPF / 独立 Runtime 架构。当前仓库已有独立世界模型、占位宠物和空间动作，不需要重建 World Lab，也不在这轮另建 Web 前端或云后端。ESP32 仍保留已有语义状态输出；正式美术、商业化及实体传输进入后续里程碑。

## 工程边界

- 健康检查仍使用原有快速预算（Desktop 700ms），模型响应预算 100 秒，覆盖现有云端 45 秒 / 本地 90 秒提供方预算；只读执行 35 秒，记忆操作 10 秒。
- 管道只接收当前 Windows 用户，一条连接处理一条请求。用户停止导致客户端断开，Runtime 通过断开检测取消模型/工具任务。取消是协作式的；已经交给外部模型的计算或费用不保证能够撤回。
- 至多四个客户端连接；额外模型/工具请求立即返回忙碌，不积累模型调用。普通上下文、健康与停止不持有 Agent 门锁。
- IPC 请求最多 65,536 字符；响应最多 262,144 字符，容纳 32,000 字符工具输出经 JSON 转义后的体积。读取时即限制帧长度；超大响应返回错误。
- 对话最多保留六个成功轮次，模型请求总长不超过 8192 字符，当前问题最多 4000 字符。超限时舍弃完整旧轮次，保留完整当前问题。会话和工具结果不持久化到文件。
- 这轮不改变默认授权范围，也不添加自动执行工具。一次提案使用后不可重放，失败/停止不自动重试工具。
- Runtime 状态更新同步，避免健康轮询覆盖模型状态。后台异常退出时也会取消并回收 IPC 工作。

## 自动验收

PR 必须通过现有全量 .NET 测试和 VS Code 检查/编译/打包；新增以下场景：

1. 人为挂起模型超过 700ms，同一实例仍能回应健康检查，并完成原请求。
2. 生成时再次发送请求，返回忙碌且模型调用次数仍为 1。
3. 客户端取消传递到模型，之后能发送下一条请求。
4. 生成期间停止 Runtime，停止请求得到确认，后台正常退出。
5. 客户端只连接不发数据时，其他连接仍能获取健康状态。
6. 32,000 个中文字符的工具响应可往返；超限和不完整请求帧被拒绝。
7. 长会话保留完整当前问题与最近完整轮次；新对话清空旧上下文。

CI 新增版本同步门禁、Desktop 与 Runtime 进程 smoke、TRX 测试证据上传。该 smoke 证明启动与正常退出，不等同于人工视觉验收。

## Windows 人工验收（尚未执行，发布前必须记录结果）

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 默认未配置 | 全新数据目录打开 Piko，单击对话 | 提示配置入口；桌宠仍可站立、移动、召回；无自动模型请求 |
| 慢模型 | 使用响应 5–30 秒的模型发送问题 | 有等待提示；托盘后台保持可用；不会启动第二个 Runtime |
| 停止/关闭 | 生成中停止，再发送；生成中关闭窗口 | 问题可重试；关闭后不追加文字、不触发迟到宠物反应 |
| 常见失败 | 无效 Key / 404 / 429 / 本地模型未启动 | 提示原因和下一步，保留输入，可编辑后重试 |
| 长输入与键盘 | 多行中文、Ctrl+Enter、空输入、4000 字符 | Enter 只换行；Ctrl+Enter 只发一次；空输入不能发送 |
| 只读操作 | 连续生成计划、选择一项、取消目录、确认执行 | 旧计划不可执行；取消不执行；一次只执行明确选择的一项 |
| 会话隔离 | 看工具结果后继续聊天，再点击新对话 | 工具结果不作为聊天上下文自动发送；新对话不含旧轮次 |
| 版面与无障碍 | 100/150/200% DPI、最小窗口、键盘 Tab、读屏 | 输入、状态、停止与执行按钮可达，没有遮挡或裁切 |
| 环境行为 | 双屏/负坐标/全屏，移动或关闭支撑窗口 | 原有跟随、掉落、隐藏、召回继续正常 |
| 稳定性 | `scripts/stability.ps1 -Version 0.2.5 -DurationSeconds 1800` | 达到脚本预算并保存 30 分钟报告 |

当前执行环境为 Linux，无 Windows 桌面/.NET SDK，不能在本地声称通过 WPF 人工验收或真实账号调用。以 PR 上的 Windows CI 运行和后续人工记录为证据。
