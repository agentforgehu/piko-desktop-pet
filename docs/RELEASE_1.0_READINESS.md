# Piko 1.0.0 正式版候选交付

当前状态：候选版开发与验证中，尚未批准正式发布。版本号为 `1.0.0`，候选包强制使用 `preview` 更新通道，并包含 `PREVIEW-CANDIDATE.txt`。它不会触发自动安装，不能作为已签名正式版宣传。

## 1.0 范围

| 角度 | 本轮交付 | 验收方式 |
|---|---|---|
| 产品管理 | 收敛到 Windows 10/11 x64 本地桌面陪伴，模型、记忆、开发感知均可选；固定版本与发布门禁 | 版本同步检查、发布批准记录 |
| 用户体验 | 首次使用引导；已有用户保留偏好并跳过引导；设置四分区；聊天停止、重试与清空 | 设置迁移测试、WPF 控件检查、真人操作 |
| 前端 | 窗口适应主屏工作区；小屏滚动；空问题禁止发送；独立记忆窗口关闭修复 | 两种客户区尺寸、三种栅格倍率的 36 张 WPF 导出图 |
| 后端 | 健康检查不被模型请求阻塞；连接关闭传递取消；有界 IPC 与历史；未知配置枚举拒绝保存 | 并发、取消、边界和配置回归测试 |
| 安装与发布 | 首装、运行中覆盖安装、默认卸载保留数据、完全卸载；稳定版签名和验收门禁 | 临时 Windows CI 用户生命周期测试、签名校验 |
| 隐私 | 清楚说明本地数据、可选模型发送内容和删除范围；数据目录缺失时完全卸载仍清理凭据 | 隐私说明与代码审查 |

## 自动证据

PR 的 `CI` 工作流验证构建、测试、Desktop/Runtime smoke 和 VS Code 扩展。`Release candidate validation` 在 `codex/1.0-*` PR 上另外生成：

- `Piko-1.0-UI-evidence`：实际 WPF 客户区渲染与按钮可见性证据。500×480 和 620×620 是 DIP 客户区尺寸；100%、150%、200% 是离屏栅格导出倍率，不是实体显示器混合 DPI 测试。
- `Piko-1.0-UNSIGNED-CANDIDATE`：未签名安装器、便携包、VSIX、preview 更新清单、SHA-256、TRX、安装生命周期报告和 30 分钟稳定性报告。

安装验证在 GitHub 临时 Windows 用户中运行，覆盖同版本替换运行中的应用与数据保留；不等同于全部历史版本和企业受管设备的升级验收。

长稳每两秒采样内存、CPU、句柄、Runtime 文件心跳和真实命名管道健康响应，要求进程按时干净退出。桌面与 Runtime 在隔离目录运行，关闭感知和外部模型；这份报告证明 CI 环境资源与 IPC 稳定性，不能替代真实桌面操作或真实模型长稳。报告记录工作流测试的提交。

以当前 PR 的绿色工作流、产物和最终说明为准；本文件不预先宣称测试通过，也不沿用旧版本的测试数字。

## 正式发布剩余条件

| 条件 | 当前状态 | 完成方式 |
|---|---|---|
| 发布者身份与联系信息 | 未确认 | 确认 Publisher、官网、隐私政策与安全联系方式；同步用户说明 |
| 可信代码签名 | 未配置 | 配置生产签名身份，将真实叶证书指纹加入 `TrustedUpdateSigners.Thumbprints`，重建并验证 |
| 真人界面与交互验收 | 未完成 | 实机确认首次启动、拖拽召回、全屏隐藏、多屏混合 DPI、四区设置、聊天停止/重试/计划确认 |
| 真实模型验收 | 未完成 | 使用发布者授权的模型端点与凭据，验证成功、超时、断网、取消、限流及用户数据发送范围 |
| 参考机器长稳 | 未完成 | 最终候选在真实 Windows 桌面至少 30 分钟，保存机器、场景、资源与异常记录；建议另做 8 小时 |
| 角色与图标确认 | 待发布者验收 | 当前原创矢量形象可继续使用；是否作为正式美术由发布者确认 |

完成上述事项并保存可追溯证据后，在 `release-approval.json` 填入已验收代码提交、证据地址和真实批准结果。`check-release-ready.ps1` 检查版本、批准项和验收后的产品/脚本变更。批准文件不是测试报告的替代品。签名身份或产品代码更改后必须针对新的代码重新验收。

稳定版工作流随后执行签名、构建验证、30 分钟稳定性门禁及 GitHub Release 发布。未完成批准时会明确失败，不会发布半成品稳定版。签名配置见 [发布安全说明](RELEASE_SECURITY.md)，版本流程见 [发布流程](RELEASE_PROCESS.md)，用户数据说明见 [隐私说明](PRIVACY.md)。
