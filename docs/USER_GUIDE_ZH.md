# Piko Desktop Pet 0.1.0 中文使用说明

## 1. 安装

1. 下载 `Piko-0.1.0-win-x64.zip`。
2. 解压到一个固定目录，例如 `D:\Apps\Piko`。
3. 双击 `Piko.exe`。

发布包是 Windows x64 自包含版本，不要求安装 .NET。首次运行如果 Windows SmartScreen 提示未知发布者，请确认文件来自本项目 Release；当前测试版尚未购买代码签名证书。

## 2. 基本操作

- 单击：Piko 向你打招呼。
- 按住并拖动：把 Piko 放到窗口顶部或桌面底部。
- 双击：打开设置。
- 右击：打开和托盘相同的控制菜单。
- `Ctrl+Alt+P`：无论 Piko 在哪里，都召回到主屏幕。
- 托盘菜单“演示互动”：立即查看散步、攀爬、跳跃、探头和休息。

## 3. 六类桌面互动

### 爬窗口边缘

Piko 会选择可用窗口的一侧向上攀爬。如果目标窗口关闭或失效，它会放弃附着并安全下落。

### 从窗口跳到另一个窗口

Piko 只在距离和高度差处于安全范围时起跳。目标消失时允许落到其他有效表面，超出桌面范围会自动召回。

### 屏幕外探头

Piko 会躲到主屏幕右侧，只保留眼睛区域。五秒后自动回来，也可以随时按 `Ctrl+Alt+P`。

### 把窗口当作家具

窗口顶部既是可站立地形，也是散步和休息表面。窗口移动时 Piko 使用相对锚点跟随，而不是停在旧坐标。

### 观察复制与下载

Piko 本地观察下载、桌面和文档顶层目录的文件变化；对于 Windows Shell 复制窗口，只有发现真实进度控件时才报告活动。它不会读取文件内容，也不会记录文件名。不同应用公开的信息不同，因此状态分为精确、估算和仅活动三种可信度。

### 在鼠标附近驻足

鼠标静止约两秒且与 Piko 位于相近表面时，Piko 会走近，但保留约 72 像素距离，几秒后离开。

## 4. 设置

可以独立关闭：

- 自主活动；
- 窗口探索；
- 鼠标感知；
- 文件活动感知；
- 状态气泡；
- 鼠标交互；
- Windows 登录后自动启动。

开启鼠标穿透后，鼠标无法直接点击 Piko，请使用托盘图标或 `Ctrl+Alt+P` 召回和打开控制。

## 5. 本地数据和恢复

本地目录：

```text
%LOCALAPPDATA%\PikoDesktopPet
```

其中：

- `settings.json`：设置和最后位置；
- `piko.log`：不包含窗口标题/文件名的滚动日志；
- `device-state.json`：未来 ESP32 可读取的眼睛语义状态；
- `diagnostics\`：用户从托盘显式导出的桌面快照。

如果上次异常退出，Piko 下次启动不会相信旧屏幕坐标，而会回到主屏幕工作区。

## 6. 退出与卸载

从托盘菜单选择“退出 Piko”。卸载时关闭 Piko 后删除程序目录；如需同时清除状态，再删除 `%LOCALAPPDATA%\PikoDesktopPet`。如果启用了开机启动，请先在设置中关闭，或在 Windows“启动应用”中关闭。

## 7. 已知限制

- 当前是原创矢量占位形象，后续可以替换为正式美术和动作帧。
- 浏览器和第三方下载器不一定公开精确百分比，此时只显示活动/估算状态。
- 当前窗口世界以约 450ms 周期更新，极速移动窗口时可能短暂滞后。
- 尚未进行商业代码签名，Windows 可能显示未知发布者。
- ESP32 本轮只定义和输出状态，尚未建立网络/串口传输。
