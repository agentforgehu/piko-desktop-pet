# Piko Desktop Pet 0.2.4 预览版中文使用说明

## 1. 安装

推荐方式：

1. 下载 `Piko-0.2.4-Setup.exe` 及同名 SHA-256 文件。
2. 核对校验值后双击 Setup；它只为当前 Windows 用户安装，不要求管理员权限。
3. 安装完成后从开始菜单启动 Piko。

也可以下载 `Piko-0.2.4-win-x64.zip`，解压到固定目录后双击 `Piko.exe`，作为免安装便携版使用。

发布包是 Windows x64 自包含版本，不要求安装 .NET。首次运行如果 Windows SmartScreen 提示未知发布者，请确认文件来自本项目 Release；当前测试版尚未购买代码签名证书。

## 2. 基本操作

- 单击：打开互动窗口；模型回复会同步到 Piko 的气泡、情绪和动作。
- 按住并拖动：把 Piko 放到窗口顶部或桌面底部。
- 双击：打开设置。
- 右击：打开和托盘相同的控制菜单。
- `Ctrl+Alt+P`：无论 Piko 在哪里，都召回到主屏幕。
- 托盘菜单“演示互动”：立即查看散步、攀爬、跳跃、探头和休息。
- 前台游戏或应用覆盖整个显示器时，Piko 自动隐藏；退出全屏或切换到普通窗口后自动恢复。

Piko 会根据已授权的本地情境表现出担心、问候、帮助和庆祝。用户正在输入或处于游戏/会议等勿扰情境时，打扰策略优先于说话；没有云端 AI 时仍使用确定性 PetMind 正常反应。

## 3. 六类桌面互动

### 爬窗口边缘

Piko 会选择可用窗口的一侧向上攀爬。如果目标窗口关闭或失效，它会放弃附着并安全下落。

### 从窗口跳到另一个窗口

Piko 只在距离和高度差处于安全范围时起跳。目标消失时允许落到其他有效表面，超出桌面范围会自动召回。

### 屏幕外探头

Piko 会躲到主屏幕右侧，只保留眼睛区域。五秒后自动回来，也可以随时按 `Ctrl+Alt+P`。

### 把窗口当作家具

窗口顶部既是可站立地形，也是散步和休息表面。窗口移动时 Piko 使用相对锚点跟随，而不是停在旧坐标。

### 观察复制与下载

Piko 本地观察下载、桌面和文档顶层目录的文件变化；对于 Windows Shell 复制窗口，只有发现真实进度控件时才报告活动。它不会读取文件内容，也不会记录文件名。不同应用公开的信息不同，因此状态分为精确、估算和仅活动三种可信度。

### 在鼠标附近驻足

鼠标静止约两秒且与 Piko 位于相近表面时，Piko 会走近，但保留约 72 像素距离，几秒后离开。

## 4. 设置

可以独立关闭：

- 自主活动；
- 窗口探索；
- 鼠标感知；
- 文件活动感知；
- 状态气泡；
- 鼠标交互；
- Windows 登录后自动启动。
- 开发活动与 Git 摘要；
- 加密本地记忆；
- 模型接入（关闭、OpenAI API、本地兼容接口）与 Agent 只读权限；
- 用户称呼、性格和低/中/高主动程度；
- 前台活动类别感知。

OpenAI API Key 仅写入 Windows 凭据管理器，不进入设置文件。本地模型必须提供 OpenAI-compatible 的 `/v1/chat/completions` 接口，并绑定在 `127.0.0.1` 或 `localhost`；本地模式不读取 API Key。模型只能返回文字、白名单情绪/动作和工具提案，不能直接执行电脑操作。

选择模型后建议点击“保存并测试模型”。Piko 会先安全保存设置并重启 Runtime，再发送一个不调用工具的最小请求。测试会明确区分 API Key 无效、模型或地址不存在、账号无权限、速率/额度限制、超时、本地服务未启动和模型输出不兼容。托盘第一行与“查看后台状态”会持续显示模型关闭、未测试、已连接或异常。

如需 VS Code 的构建、测试、诊断数量和 Git 摘要感知，在扩展视图中选择“从 VSIX 安装”，安装发布包内的 `piko-context-bridge-0.2.4.vsix`，然后在 Piko 设置中开启开发活动和 Git 摘要。扩展不会发送源码、文件名、诊断正文、终端输出或仓库路径。

托盘菜单“检查正式版更新…”仅在用户点击时联网。正式版只有通过大小、SHA-256、Windows Authenticode 和发布者证书指纹四重校验后才会自动交给安装器；当前未签名预览版只会打开 GitHub Release 页面。

开启鼠标穿透后，鼠标无法直接点击 Piko，请使用托盘图标或 `Ctrl+Alt+P` 召回和打开控制。

## 5. 本地数据和恢复

本地目录：

```text
%LOCALAPPDATA%\PikoDesktopPet
```

其中：

- `settings.json`：设置和最后位置；
- `runtime-settings.json`：后台权限开关和非敏感 AI 配置；
- `piko.log`：不包含窗口标题/文件名的滚动日志；
- `memory.db`：字段加密的本地记忆数据库；
- `agent-audit.jsonl`：不记录路径、参数和正文的 Agent 执行审计；
- `device-state.json`：未来 ESP32 可读取的眼睛语义状态；
- `diagnostics\`：用户从托盘显式导出的桌面快照。

如果上次异常退出，Piko 下次启动不会相信旧屏幕坐标，而会回到主屏幕工作区。

## 6. 退出与卸载

从托盘菜单选择“退出 Piko”。安装版可在 Windows“已安装的应用”中卸载，默认保留本地设置和记忆；完全清除可运行 `Piko.Setup.exe --uninstall --purge-data`。便携版关闭 Piko 后删除程序目录即可。卸载器会移除开始菜单、应用注册和开机启动项。

## 7. 已知限制

- 当前是 `0.2.4` Pre-release，已具备 API/本地模型连接测试、状态可见性、宠物表达闭环和安装/卸载/更新验证链；正式 `1.0` 仍需要正式动画、三层记忆、发布者签名、真实 AI 账号验收和最终长稳报告。
- 当前是原创矢量占位形象，后续可以替换为正式美术和动作帧。
- 浏览器和第三方下载器不一定公开精确百分比，此时只显示活动/估算状态。
- 当前窗口世界以约 450ms 周期更新，极速移动窗口时可能短暂滞后。
- 尚未进行商业代码签名，Windows 可能显示未知发布者。
- ESP32 本轮只定义和输出状态，尚未建立网络/串口传输。
